Para sugerir um tema, apontar uma possível atribuição incorreta ou relatar um erro no site, você pode abrir uma solicitação no repositório público do projeto.

Enviar sugestão pelo GitHub

Importante sobre este canal

As solicitações abertas no GitHub podem ficar visíveis publicamente. Não inclua senhas, documentos, dados financeiros ou outras informações pessoais ou confidenciais. Este canal não é um formulário privado e não há garantia de resposta em prazo específico.

Se preferir um canal privado, será necessário disponibilizar um endereço de e-mail de contato do responsável pelo projeto. Nenhum endereço foi publicado aqui para evitar inventar ou divulgar um contato não confirmado.
