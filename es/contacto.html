Importante sobre este canal

Las solicitudes abiertas en GitHub pueden ser públicas. No incluyas contraseñas, documentos, datos financieros ni otra información personal o confidencial. Este canal no es un formulario privado y no se garantiza una respuesta en un plazo determinado.

Para un canal privado sería necesario publicar una dirección de correo verificada del responsable del proyecto. No se indica ninguna dirección aquí para evitar inventar o divulgar un contacto no confirmado.
