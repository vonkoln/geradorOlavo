Redaktioneller Kontakt

Für Themenvorschläge, Hinweise auf möglicherweise falsche Zuschreibungen oder Fehlermeldungen können Sie eine Anfrage im öffentlichen Repository des Projekts eröffnen.

Vorschlag über GitHub senden

Wichtiger Hinweis zu diesem Kanal

Auf GitHub eröffnete Anfragen können öffentlich sichtbar sein. Teilen Sie dort keine Passwörter, Dokumente, Finanzdaten oder andere persönliche bzw. vertrauliche Informationen. Dieser Kanal ist kein privates Formular; eine Antwort innerhalb einer bestimmten Frist wird nicht garantiert.

Für einen privaten Kontakt müsste eine bestätigte E-Mail-Adresse der Projektverantwortlichen veröffentlicht werden. Hier wird keine Adresse angegeben, um keinen unbestätigten Kontakt zu erfinden oder offenzulegen.
